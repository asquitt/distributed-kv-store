# Distributed Key-Value Store

A production-grade distributed key-value store implementing Raft consensus, built from scratch.

## Status: Phase 1 - In Progress 🚧

## Project Goals
- Implement Raft consensus algorithm
- Build fault-tolerant distributed storage
- Demonstrate deep systems programming knowledge

## Tech Stack
- Go 1.21+
- gRPC for inter-node communication
- Protocol Buffers
